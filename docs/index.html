Exact inside the assumptions.
The native engine branches only on steps that run. This browser independently enumerates potential terminal outcomes for every step, schedules completion events, then sums over unused outcomes of skipped steps. Both retain the same complete finite history law.
Retries assume each failure is independent, with an unchanged supplied rate and immediate retry. No backoff, queueing, timeouts, correlated outages, side-effect safety or capacity limits are modeled. Reusing a tool name does not make its failures correlated.
These are established geometric, reliability and stochastic-project calculations. Enumeration is exponential and deliberately small. Exact fractions describe the declared model, not empirical confidence or production reliability. The original simulator uses binary floats and a seeded random stream; rational reports do not promise identical seed traces.
